> **初めてros2canを触る人向けの簡易版ガイドです。**
> 全機能を網羅した詳しいマニュアルは [こちら](index.md) を見てください。

このページだけで「インストール → 起動 → 実機なしで動かしてみる → 止め方」
までを一通り体験できます。CubeMars/ロボマスの細かい制御モードや、外部ノードの
書き方、ファームウェア生成などは扱いません（必要になったら本編マニュアルへ）。

## 1. これは何？

`ros2can` は、CANバスにつながったマイコン（サーボ・モータ・センサ等）を
PC からGUIで直接操作するためのROS 2アプリです。実機が無くても、
「仮想デバイス」を使えば画面の動作確認だけならすぐに試せます。

## 2. 準備

```bash
sudo apt install python3-pyqt5 python3-serial
```

実機を使う場合は、USBシリアルのポート権限が必要です（初回のみ）。

```bash
sudo usermod -aG dialout $USER
# 反映のため一度ログアウト/ログイン(またはPC再起動)してください
```

## 3. ビルドと起動

```bash
cd ~/ros2_ws
colcon build --packages-select ros2can
source install/setup.bash
ros2 run ros2can ros2can
```

起動すると、こういう画面が出ます（実機がまだ何も繋がっていない状態）。

![起動直後の画面](images/01_startup_placeholder.png)

## 4. 実機なしで動かしてみる

ツールバーの「**デバッグデバイスを追加（実機不要）…**」を押し、
適当な数字（例: `1`）を入力してください。仮想デバイスが一覧に追加されます。

![デバッグデバイスを追加した直後](images/02_device_added.png)

追加したデバイスをクリックすると、右側に操作パネルが出ます。

## 5. Control タブ: 値を送ってみる

**Control** タブでスライダーを動かし、右上の「**ダイレクト送信**」に
チェックを入れてください（このチェックが入るまでは何も送信されません＝
誤操作防止の安全装置です）。

![Controlタブ](images/03_control_tab.png)

## 6. Monitor タブ: 値を見てみる

**Monitor** タブに切り替えると、センサ側の値（スイッチのON/OFF、
エンコーダのカウント値など）が見られます。仮想デバイスでは、この画面から
スイッチを直接ON/OFFしたり、カウント値を打ち込んだりして、実機のセンサ入力を
再現できます。

![Monitorタブ](images/04_monitor_tab.png)

## 7. 止め方

ツールバー右寄りにある赤い「**■ 全デバイス E-STOP**」を押すと、
全デバイスへゼロ指令を送って送信を止められます。迷ったらまずこれを
押してください。ウィンドウを閉じるだけでも安全側（ゼロ指令送信）に
倒れるようになっています。

## 8. 実機を繋ぐ場合

`xiao_esp32_s3_smd_serial_bridge`（MODE_CAN_HOST）を書き込んだ基板をUSB接続
するだけで、ros2canが自動的に検出してデバイス一覧に表示します。特別な操作は
不要です。うまく検出されない場合は、本編マニュアルの
[4. 起動直後の画面](index.md#4-起動直後の画面) にあるトラブルシューティングの
項目を確認してください。
